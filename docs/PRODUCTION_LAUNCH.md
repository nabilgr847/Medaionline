# Production Launch Gate

This source code does not itself authorize a healthcare business to operate.

Before accepting real patients:
1. Obtain legal advice on applicable Bangladesh healthcare, telemedicine, professional, privacy, data protection, consumer, and cross-border processing requirements.
2. Confirm required licenses/approvals and professional verification with the relevant authorities.
3. Appoint clinical governance leadership and validate clinical workflows.
4. Complete threat modelling, independent penetration testing, dependency review, and secure code review.
5. Move medical files from local disk to private, encrypted object storage with malware scanning and tested backups.
6. Implement consent, access/correction/export/deletion, retention, breach response, and audit procedures.
7. Validate AI outputs using clinician-reviewed test sets; AI must not diagnose or prescribe autonomously.
8. Contract and test email/SMS, video, storage, monitoring, and payment providers as applicable.
9. Test disaster recovery, service monitoring, incident response, and support escalation.
10. Run a controlled pilot with clinician oversight before any wider launch.
